## 📌 Project Overview
The **Construction Materials Cost Planner** is a modular Python application designed to bridge structural concrete quantity estimation with site procurement analysis. The application consists of two connected modules:
1. **Module 1 (Material Quantity Calculator):** Calculates concrete volumes and standard material requirements (cement, sand, aggregate) per element and site with waste factor consideration.
2. **Module 2 (Purchase & Cost Analysis):** Cleans and merges procurement transactions with price databases, monitors shortages/surpluses, runs NumPy-based price inflation simulations, and exports visual analytics.
